## 로컬 작업

- **재고 위치 필터 A안 선택·제품 적용(배포 준비):** `/inventory-study`에서 A 모든 항목 사이 짧은 선·B 구분선 없음·C 전체 뒤 선 하나를 나란히 비교한다. 세 안 모두 30px 밑줄이 200ms 감속 이동하며 동작 줄이기 설정에서는 즉시 전환한다. 연속 선택·이동 중간/최종 위치·밑줄 중앙 정렬을 확인했다. 시안은 `scripts/inventory-location-study.ts`에 보존했고, 선택된 A안(배경판 없음·구분선 네 개·밑줄 이동)을 `inventory.module.css`에 적용했다. 예시 재고로 위치 전환, 320/390px 반응형·48px 터치 영역·가로 넘침 없음, 관련 lint 확인. 제품 관련 브라우저 12개 통과. 사용자가 거래처 변경과 함께 Git main·Hosting 배포를 명시적으로 요청했다.

- **배포 후 간격 재조정(미배포):** `codex/compact-ceramic-spacing`에서 거래처 모바일 본문을 다른 모드와 같은 좌우 12px로 맞추고, 왼쪽의 중복 scrollbar gutter를 없앴다. 오른쪽 native gutter·스크롤 중에만 바 표시 유지. 버튼 최소 높이 132→112px, 안쪽 여백 세로 8px·가로 6px, 패널 폭 `min(92%, 18rem)`·본문 가운데 정렬(390px 화면에서 각 버튼 143×112px), 문구는 `이름으로 찾기 / 전체보기 / 납품사진 / 거래처 등록`. 재고 모바일 헤더 아래 여백 18→8px·본문 위 7.2→4px. 헤더/웰컴 사이 1px 선은 **미확정 비교안이며 로컬 preview 전용**이다. 관련 브라우저 46개 최종 통과(44개 최초 통과 + 이전 버튼명을 찾던 테스트 수정 후 2개 재검사 통과), CustomerHome 단위 3개·관련 lint·diff 검사 통과. 후속 가로 폭 축소 후 320/390/430/1280px 레이아웃·접근성·스크롤바 관련 4개 재검사 통과. 실제 기기·CI·운영 build/재배포는 하지 않았다. `npx tsx scripts/preview-customer-ceramic.ts`로 실행하고 체크박스로 선을 비교한다. 재고도 합성 읽기 전용 데이터로 확인 가능하다.

- 거래처 세라믹 2×2 패널은 main 병합·운영 배포 완료. 상단 유리 모드 유지, 검색/전체보기/납품사진/등록 순서, 중앙 정렬·저채도 입체 표면·가운데 홈 반영. 모바일 기본 좌우 8px와 대칭 스크롤바 공간을 확보하고 스크롤 중에만 바를 표시한다. 홈 설정은 제외하고 학교/영업 설정·재고 옵션 경로를 유지한다. [디자인·로컬 미리보기 기록](customer-ceramic-panel-20261101.md) · [릴리스 검증](releases/2026-11-01-customer-ceramic.md)

## 남은 작업

1. **Android 실기기 확인:** 휴대폰 연결이 가능해지면 Chrome 일반 탭과 설치 PWA의 하단 시스템 버튼을 비교한다. 정확한 Android·One UI·Chrome 버전, 밝음/어두움 설정, 재실행·복귀·키보드 상태를 기록한다. 설치 manifest 갱신을 확인하고 앱 삭제·데이터 초기화는 하지 않는다.
2. **현장 인수:** 최신 UI·사진 촬영/업로드·홈 복귀·설치 PWA의 키보드/뒤로가기를 실기기에서 확인한다. 데스크톱 모바일 에뮬레이션 통과와 구분한다. 실제 현장망 지연·동시 사용자 읽기 비용은 별도 계측 대상이다.
3. **검사 범위 개선:** 실제 이미지 교체의 presentation CI 78개 UI 검사 통과, workflow 5분 28초를 확인했다. 기능별 축소는 의존관계가 확인된 범위만 추가한다.
4. **과거 보류 사항:** 2026-09-26 거래처 일괄 등록 준비 기록은 이후 완료 여부가 확인되지 않았다. 재개 요청 시 보관본과 최신 운영 상태를 먼저 대조한다. 과거 등록 자료나 대기 기록만으로 운영 쓰기를 실행하지 않는다.

## 작업·검증 방법

- [범위별 검증 규칙](scoped-verification-20261031.md): 문서는 `docs`, 허용된 표현 변경은 `presentation`, 기능·보안·설정·불확실 변경은 `full`. 관련 로컬 검사부터 실행하고 동일 결과를 반복하지 않는다.
- CI 구성의 [전체 경로 검증](https://github.com/kim-DL/ONWAY/actions/runs/41146903811)은 통과했다. [문서 경로 검증](https://github.com/kim-DL/ONWAY/actions/runs/41148064803)은 plan/verify만 실행해 35초에 완료됐다. 이는 당시 측정이며 향후 시간 보장이 아니다.
- 개발은 `npm run dev`. 단위 검사는 관련 파일을 지정하고 필요한 `npm run typecheck`와 lint를 실행한다. 전체 검사·운영 빌드는 변경 범위와 릴리스 조건에 맞춰 선택한다.
- Hosting 배포는 별도 승인 범위와 검증된 후보만 사용한다. 상세 보안·데이터·배포 계약은 AGENTS.md를 따른다. 문서 정리 때문에 앱을 재빌드·재배포하지 않는다.
