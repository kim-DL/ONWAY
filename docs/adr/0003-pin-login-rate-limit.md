# ADR 0003: PIN login rate-limit baseline

- 상태: 승인
- 날짜: 2026-08-23

## 결정

- 서버가 암호학적으로 안전한 고유 6자리 PIN을 무작위 발급한다. 휴대폰·생년월일·직원 코드·별칭에서 파생하지 않는다.
- HMAC Lookup Key와 느린 검증 Hash는 서로 다른 Secret을 사용하며 PIN 원문은 저장·로그·Cache하지 않는다.
- 동일 PIN Lookup의 실패 5회부터 15분 잠그고, 반복 잠금은 단계적으로 늘린다.
- App Check 식별자와 네트워크 출처 단위로 10분당 30회 상한을 두며 초과 시 60분 제한한다.
- 오류 응답은 PIN 존재 여부, 직원 상태, 잠금 대상을 구분해 노출하지 않는다.
- 성공 로그인, 실패 누적, 잠금, 관리자 재발급·해제는 민감값 없이 Audit Event로 남긴다.

## 조정 원칙

Pilot에서 정상 직원의 잠금 빈도와 공격 징후를 함께 측정한다. 수치 변경은 보안을 낮추는 임의 UI 설정이 아니라 서버 설정 Version과 Audit를 가진 관리자 변경으로 처리한다.
