## 변경

- 사용자가 요청한 ‘대인’ 대화방의 납품사진 캡처를 확인했다. Kakao Bridge public preview로 상태·열린 창·화면을 확인하고, 첨부 다운로드 미지원으로 카카오톡의 사진 뷰어를 사용했다. 검색 입력을 변경하지 않았고 메시지·파일을 보내지 않았다.
- 명세서 등록은 겹친 문서 3장과 스캔하는 휴대폰, 경로 추천은 접힌 지도·경로·핀의 직접 제작 SVG를 사용한다. 외부 이미지·아이콘 라이브러리 추가 없음.
- 두 버튼은 차분한 블루/청록 표면과 두께가 있는 하단 그림자, 클릭 시 눌림 효과를 사용한다. 이전 `.workspace button`이 기본 배경·테두리를 덮던 문제는 전용 선택자 우선순위로 해결했다.
- 납품사진의 별도 복귀 버튼을 제거했다. 해당 화면에서 활성 ‘거래처’ 모드 클릭은 기존 `closeCustomerPage`로 연결하며, 다른 화면의 활성 모드 동작과 다른 모드 전환은 유지한다. 기존 기록 복원·브라우저 뒤로 가기·페이지 복원 시 홈 복귀 계약을 유지한다.
- 제목과 건수를 왼쪽에 묶고 순서 편집을 오른쪽으로 옮겼으며 검색창 주변 여백을 줄였다. 명세서/경로 추천 처리와 자동 적용 로직은 변경하지 않았다.
- SVG 두 개를 PWA precache에 추가했다. Hosting 검증은 정확한 파일 목록·해시·크기 및 원격 SVG MIME을 확인하도록 확장했다.
