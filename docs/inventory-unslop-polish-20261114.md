# 재고 모드 가독성과 필터 표시 개선

2026-11-14 로컬 구현 완료. `unslop-ui`로 재고 목록·품목 상세·목록 옵션을 점검하고 확인한 문제를 수정했다. 브랜치는 `codex/inventory-unslop-polish`, 시작 소스는 `cbb5784`이다. 운영 배포는 수행하지 않았다.

[heydamir의 Unslop](https://github.com/heydamir/unslop)을 기존 화면의 작은 문제를 다듬는 polish mode로 적용했다. 제품은 현장에서 수량과 유통기한을 확인하는 재고 화면, 성격은 차분하고 정확한 업무 도구, 사용 환경은 냉장·냉동 창고와 휴대폰으로 정했다. 수량의 파란색과 유통기한의 붉은색을 강조로 삼고 기존 유리 내비게이션과 보관 장소 선택 방식을 유지했다.

## 발견과 변경

| 발견한 문제 | 반영 |
|---|---|
| 상세의 임박 경고 10px, 제조사 같은 항목 이름 11px, 실사 안내 10px | 해당 정보를 14px로 조정했다. 유통기한 수정과 하단 작업 버튼도 14px로 맞췄다. |
| 목록 보조 정보의 좁은 줄 간격 | 제조사·유통기한 정보를 14px로 조정하고 줄높이와 정보 사이 간격을 늘렸다. 제목은 기존 16px이다. |
| 긴 한글이 음절 중간에서 끊김 | 제목·목록 설명·상세 값에 단어 단위 줄바꿈을 적용했다. 긴 공백 없는 문자열은 줄을 넘길 수 있도록 했다. |
| 임박 필터 설명이 작은 `D-7일` 문구에 머묾 | 설정된 일수에 따라 `7일 이내 · 기한 지난 품목 포함`처럼 풀어 썼다. |
| 옵션을 닫으면 어떤 필터가 적용됐는지 알기 어려움 | 실제 임박 필터가 작동할 때 목록 상단에 `임박·기한 경과만 표시`를 표시한다. 비활성 품목 보기나 날짜 기준 미확인으로 필터가 정지한 때에는 표시하지 않는다. |

색과 재질을 일괄 변경하거나 장식 요소를 추가하지 않았다. 유통기한 경고의 `#b83244`·`#fff0f2`, 업무 버튼의 의미별 색과 기능을 유지했다. 사진·재고 수량·날짜 판정·권한·저장 및 완료 처리는 변경하지 않았다.

## 확인 결과

- 기존 inventory-ui, inventory-detail, inventory-model, inventory-count-badges 단위 검사 64개가 통과했다.
- 설정 이동·목록 키보드/복귀·수량 입력의 브라우저 검사와 신규 필터 표시 검사 총32개가 최종 소스에서 통과했다. 새 검사는 옵션 닫기, 설정 왕복, 비활성 보기 중 필터 정지, 필터 해제 후 전체 목록 복귀를 포함한다.
- 프런트엔드 타입 검사, 관련 ESLint와 diff 검사가 통과했다.
- 최종 운영 형식 빌드와 PWA·성능 용량·Hosting artifact 검사가 통과했다. 기존 용량 한도는 변경하지 않았다. CI 실행이나 운영 배포를 수행한 결과는 아니다.
- Aside에서 실제 컴포넌트의 합성 데이터를 사용해 320/390/430/1280px 상세를 확인했다. 가로 넘침이 없고 상세의 버튼은 모두 최소44×44px이었다. 임박 경고는14px이었다. 320px에서 루트 글자 크기200%·강제 고대비 조건의 가로 넘침과 경고 문구 유지도 확인했다. 실제 브라우저 배율 확대나 실물폰 검증과는 구분한다.
- 같은 합성 목록에서 임박 필터를 켰을 때24개 중16개와 필터 안내가 표시되는 것을 Aside로 확인했다. 실제 업무 자료를 사용하지 않았다.

합성 미리보기는 `output/inventory-unslop-20261114/preview.ts`로 실행하며 I/O 대체와 CSP `connect-src 'none'`으로 운영 연결을 차단한다. 생성 HTML, 로그와 성능 진단도 같은 Git 제외 폴더에 있다. 미리보기의 저장 동작은 차단된다.

Aside의 상세 화면 캡처는 반복해서 시간 초과돼 구조·글자 크기·위치 확인을 계속하고 격리 Chrome의 화면 표시로 보완했다. Chrome 도구의 지정 경로 파일 내보내기도 workspace-root 제한으로 거절됐으므로 그 경로의 캡처 파일은 결과물로 제공하지 않는다. 도구의 캡처 문제를 제품 결함으로 판단하거나 우회 저장하지 않았다. 실물 휴대폰·설치 PWA 및 실제 운영 데이터의 저장·업로드는 이번 범위에서 실행하지 않았다.
