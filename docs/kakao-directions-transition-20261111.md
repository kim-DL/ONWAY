# 카카오맵 전환 화면 개선

2026-11-11. 사용자가 카카오맵으로 넘어가기 전 작은 기본 HTML 안내문이 보이는 현상을 신고했고, 수정 후 배포까지 명시적으로 승인했다. 앱 Hosting만 배포하며 Functions·MCP·기존 업무 데이터·자격 증명은 변경하지 않는다.

## 원인과 수정

길안내 클릭 순간 팝업 차단을 피하기 위해 `about:blank` 창을 먼저 예약하고, 등록 주소를 조회한 뒤 카카오맵으로 이동하는 기존 흐름이었다. 예약 창에 `주소 확인 중…` 문구만 직접 넣어 기본 글꼴·여백으로 보였고, 모바일 화면 폭 설정도 없었다. 실제 컴포넌트와 지연시킨 예시 주소 조회로 모바일320px/PC에서 재현했으며 변경 전 새 화면 테스트2개가 실패하는 것을 확인했다.

- 눈에 보이는 작은 안내문을 제거하고 기존 앱과 같은 색·속도의 원형 로딩 표시만 중앙에 놓았다. 화면 폭 설정, 한국어 문서·제목, 스크린리더용 상태 이름을 넣었다. 모션 감소/강제 색상 설정에서는 회전을 멈춘다.
- 사용자가 누르는 순간 새 창 예약과 opener 분리는 유지한다. 주소 기반 좌표 재조회, 조회 실패 시 창 닫기·오류 안내, 팝업 차단 시 현재 창 이동, 늦은 응답·사용자 창 닫기·중복 클릭 방어를 유지한다.
- 전환 화면 코드는 기존 클릭 시 주소 조회 모듈과 함께 로드한다. 새 지연 로딩 경계나 의존성은 추가하지 않았다. 초기 화면의 공용 코드에 일괄 포함하지 않는다.
- Callable·App Check·세션/권한 확인과 등록 주소 우선순위, 거래처/납품 목록/사진/줄임말 데이터 계약은 바꾸지 않았다. 운영 데이터를 시험용으로 생성·수정·삭제하지 않는다.
