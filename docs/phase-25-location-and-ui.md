# 위치 판별·지역 필터·오로라 개선 — 2026-09-05

## 운영 오류 근거

운영 `optimizeSalesRoute` 경고 로그에서 20곳/21곳 요청이 반복적으로
`SCH-NEIS-7451016`의 `review-required`로 HTTP 400을 반환한 것을 확인했다.
대전괴정중학교의 공식 도로명 주소는 `대전광역시 서구 가장로 15`이다.
카카오 본교 후보는 정확한 교명·주소로 100점이었지만, 같은 주소에 있는
`대전괴정고등학교 행정실`(학교부속시설)이 60점 경쟁 후보로 남았다.
따라서 재시도 횟수나 학교 수가 아니라 장소의 정체성을 구분하는 문제였다.

## 수정 범위와 안전 경계

- 본교 교명·도로주소·대전 지역·학교급 카테고리가 정확히 맞아야 자동 매칭한다.
- 같은 교명 어근, 다른 학교급, 같은 주소, 본교에서 500m 이내인
  **행정실·교무실·강당 / 학교부속시설**만 별도 경쟁 후보에서 제외한다.
- 동일급 타교, 동명 본교의 다른 장소 ID, 분교·캠퍼스, 불명 시설, 카테고리
  불일치, 장소 ID 충돌은 자동으로 무시하지 않는다. 원본 후보는 모두 보존한다.
- 고등학교 아래의 특목고·자사고 등 실제 카카오 세부 분류도 허용 목록으로 검증한다.
  실제 외국어고·대신고의 하위 카테고리 회귀 사례를 테스트로 고정했다.
- 주소 조회만 타임아웃/오류일 때 학교명 조회 한 번으로 복구를 시도한다.
  이때 거리 점수는 부여하지 않고, 정확한 교명·주소·구의 90점 기준을 유지한다.
- 401/403/429는 후속 엔드포인트 조회를 하지 않는다. 429를 즉시 보존해
  재시도 중 503/타임아웃으로 덮여 추가 호출되는 경우를 차단한다.
- 빈 문자열·null·범위 밖 좌표 응답을 유효 숫자로 변환하지 않는다.
- 관리자 확정 좌표, 이전 가능성, 동시 수정의 revision 검증과 감사 기록은 유지한다.
- 진짜 검토 대상에는 단순 재시도로 해결되지 않을 수 있음을 안내한다.

## 운영 데이터 검증 및 복구

`scripts/audit-route-location-readonly.mjs`는 최근 12시간 경고 30건과
신고 학교/매칭 검토 문서만 조회한다. 인증 정보와 직원 정보는 출력하지 않는다.

`scripts/verify-route-location-live.mjs`는 기본 읽기 전용이다. `--audit-all`로
현재 월 배정 학교 22곳을 실제 카카오에서 새로 조회했고 **22/22 고신뢰도 일치**했다.
실제 좌표·도로 API로 괴정중학교를 첫 학교/중간 학교로 두는 두 경로 모두
**22곳, 도로 구간 21개, 추정 구간 0개**를 확인했다. 누락은 허용하지 않는다.

사용자가 요청한 신고 학교에 한정한 `--apply`로 기존 매칭 서비스를 실행했다.
변경 전 학교/검토 문서 백업을 `output/security/route-location-SCH-NEIS-7451016-1788617791829.json`에 보관했고,
기존 트랜잭션·감사 절차로 `needsReview` → `autoMatched`, revision 12 → 13을 저장했다.
직원 토큰을 발급하지 않았으며 담당 배정·방문 기록·PIN은 변경하지 않았다.
실제 직원 PWA에서 인증된 버튼을 누르는 검증과 위 서버/지도 검증은 구분한다.

## UI 및 접근성

- 회전 테두리: 18초 → 8초, 내부 선 2px, 공통 파랑과 회사 초록의 대비 강화.
  지속 정지 설정, OS 동작 감소, 고대비 모드는 유지한다.
- 오로라: 양 업무 모드 공통 청백색, 파란 상단광과 옅은 민트 하단광.
  정적인 배경과 낮춘 입자 농도로 텍스트/카드가 우선 읽히도록 했다.
- 지역 필터: 중립 배경 위 선택된 흰색 면과 파란 강조선, 지역별 학교 수.
  넘치는 영역은 지역 탐색 버튼과 가장자리 음영을 제공한다.
- 최소 44px 터치 영역, 12px 학교 수, 단일 선택 radio semantics,
  방향키/Home/End/Tab, 수평 영역 내부 스크롤만 사용한다.
- 실시간 배정 삭제로 선택 지역이 사라져도 0곳 상태를 유지해 전체 지역으로 복귀 가능.
- 회사 로고·설치 아이콘·기존 업무 데이터 계약은 변경하지 않았다. PWA 캐시는 phase25.
