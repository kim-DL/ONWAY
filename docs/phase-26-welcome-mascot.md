- 앱 에셋: `/brand/bloub-welcome-v1.webp` (429,484 bytes),

- 위 경로는 당시 배포된 퇴역 v1 자산의 기록이며, 현재 저장소에서는 OPT-1C 정리로 제거되었다.

- 재생성: `node scripts/prepare-welcome-mascot.mjs "원본 GIF 경로"`.
  변환·전 프레임 검증이 모두 성공한 뒤에만 앱 에셋을 출력한다. 원본은 수정하지 않는다.

## 재생 및 접근성

- 화면에 보이는 동안 타이머 없이 전체 루프가 반복된다.
- 페이지가 숨겨지거나 캐릭터가 화면 밖에 있으면 정지 이미지를 사용하고,
  다시 보이면 자동으로 재생한다. 별도 프레임 타이머나 애니메이션 라이브러리는 없다.
- 기존 저장 키를 유지한 **설정 → 화면 애니메이션**으로 캐릭터와 모드 테두리를
  함께 끄거나 켠다. 꺼짐 상태는 새로고침·재접속 후에도 유지한다.
- OS 동작 줄이기 및 강제 색상 모드에서는 자동 재생하지 않는다.
  SSR도 정지 이미지를 사용해 설정 확인 전 애니메이션이 잠깐 보이지 않게 한다.
- 캐릭터는 장식이며 빈 alt/aria-hidden을 적용하고 포커스·터치를 가로채지 않는다.
- 애니메이션 로드 오류는 정지 이미지로 대체한다. 정지 이미지마저 실패하면
  깨진 이미지 표시만 숨기며 인사말과 업무 화면은 유지한다.
- PWA 캐시는 phase26. 두 공개 에셋만 명시적으로 사전 캐시/허용 목록에 추가했다.
