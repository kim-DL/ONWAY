## 구현과 접근성

- 별도 라이브러리 없이 작은 TypingGreeting 컴포넌트만 글자 단위로 갱신한다.
- Intl.Segmenter로 한글 음절·결합 문자·이모지 묶음을 분리한다.
- 최종 문장의 모든 글자 공간을 유지하고 visibility만 바꿔 카드 높이·줄바꿈을 고정한다.
- 입력 중인 글자 옆의 가는 커서는 완료 즉시 사라진다. 반복 점멸 없음.
- 화면 읽기 도구에는 문장 전체를 한 번 제공하고 시각 효과는 aria-hidden으로 분리한다.
- 서버 렌더는 완전한 텍스트. hydration과 시간대별 인사·저장 설정 확인 후 효과를 시작한다.
- 사용자 애니메이션 끄기·OS 동작 감소·강제 색상에서는 완전한 문구를 즉시 표시한다.
- 문구가 화면 밖이거나 탭이 숨겨지면 남은 타이핑을 멈추고 복귀 시 이어간다.
  문구와 Quantum 장식의 가시성은 각각 관찰해 짧은 화면에서도 인사가 비지 않는다.
- 모든 타이머와 관찰자를 정리한다. PWA 캐시 phase29. Firebase/보안 규칙/업무 데이터 변경 없음.
