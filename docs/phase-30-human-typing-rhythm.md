# 사람이 입력하는 듯한 웰컴 리듬 — 2026-09-06

## 요청과 근거

- 고정 42ms 간격과 약 2초 강제 압축 때문에 빨리 훑고 지나가는 인상을 개선한다.
- [Fuchs & Krivokapić (2016)](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2016.01678/full)는
  단어·쉼표·마침표 경계의 키 입력 간 휴지가 다름을 보고한다. 독일어 성인 실험이므로
  한국어 표시 속도의 최적값으로 가져오지 않고, 경계에 따른 리듬의 근거로만 참고했다.
- [IBM Carbon Motion](https://carbondesignsystem.com/elements/motion/overview/)의 표현적 동작과
  업무 반응성·정적 대안 원칙에 따라 인사만 연출하고 업무 버튼 사용을 지연하지 않는다.
- 아래 숫자는 연구의 측정값이 아니라 앱 화면에 맞춘 디자인 조정값이다.

## 변경

- 첫 글자 280ms, 단어 안 글자 105–145ms의 작고 반복 가능한 속도 변화.
- 새 단어 첫 글자는 60ms 더 여유 있게, 쉼표 뒤 390ms, 문장 사이 540ms 쉬기.
- 마지막 구두점도 약간 여유 있게 입력한 후 커서는 즉시 없앤다. 완료 후 대기/반복 없음.
- 커서가 공백 입력 때 사라지지 않고 마지막 글자 옆에 머물도록 보완했다.
- Math.random·오타·삭제·자모 분해 연출은 넣지 않는다. 한글/이모지는 완성된 글자 단위 유지.
- 기존 타이핑 완료 상태, 페이지 재진입 재생, 스크롤·탭 숨김 정지/이어가기,
  동작 감소·접근성·문장 공간 고정은 유지한다. Quantum 장식과 업무 기능 변경 없음.
- 자연스러운 일정으로 8초를 초과할 예외적으로 긴 문장은 바로 모두 보여준다.
  긴 문장을 인위적으로 가속하거나 수십 초 기다리게 만들지 않는다.
- 순수 일정 함수와 단위 검사로 재현 가능한 리듬을 검증한다. PWA 캐시 phase30.
