# 동작과 디자인을 유지하는 최적화 — 2026-09-06

## 범위와 판단

- 전체 소스의 정적·동적 import, 테스트·운영 스크립트, 공개 리소스 사용처를 함께 점검했다.
- 고아 소스 파일이나 제거 가능한 직접 의존성은 발견하지 못했다. 테스트, 도메인 계약,
  이전 PWA가 참조할 수 있는 공개 아이콘·캐릭터 URL은 무작정 삭제하지 않는다.
- React 성능 가이드와 설치된 Next 16.3.2의 lazy-loading/CSS/production 문서를 기준으로
  기능을 쓰기 전 실행하지 않아도 되는 코드, 반복 생성, 실제 도달하지 않는 CSS에 집중했다.
- 데이터베이스, 서버 함수, 권한/인증 정책, 입력·저장 규칙, 앱 디자인 변경 없음.
  네트워크 확인은 완료된 결과를 캐시하지 않아 인증·오프라인 판정의 최신성을 유지한다.

## 정리 및 개선

1. `globals.css`에서 적용될 수 없는 `@media not all` 테마, 퇴역 클래스 52개,
   이전의 동일 중복 규칙 4개를 제거했다. 335,305 → 294,444바이트(12.19% 감소).
   소스 AST에서 허용된 삭제를 제외한 선택자·선언·미디어 조건·적용 순서는 동일했다.
   동적 버튼/뱃지 변형, 키보드 포커스, 고대비, 동작 감소, 고정 하단 동작은 유지했다.
2. 사용처가 없는 Firestore converter 인스턴스 10개와 동선 오류 래퍼 함수를 제거했다.
   공통 변환 함수·도메인 스키마·실사용 converter 15개는 유지하고 왕복 변환 검사를 추가했다.
3. 방문 동선·학교 추가 입력기를 `next/dynamic`으로 분리했다. 팝업을 열 때 실행하고,
   준비 중에도 닫기·포커스 복원·재열기가 가능하다. 기존 입력기 마운트/저장 동작은 같다.
   PWA는 분리된 JS/CSS도 사전 저장하므로 이 변경이 오프라인 코드를 제거하지 않는다.
4. Icon의 29종 SVG 내부 요소 79개를 호출마다 만들지 않고 정적으로 재사용한다.
   선택된 SVG 외곽과 크기/색/접근성 속성은 기존 그대로다. 학교 Map 중복 생성도 제거했다.
5. 동일 제한시간의 동시 연결 확인을 한 요청으로 공유한다. 완료 후에는 새로 확인한다.
   재연결 이벤트가 기존 재시도 타이머를 중복시키지 않게 하고, 오래된 연결 응답이
   최신 오프라인 상태를 덮거나 복구 구독을 남기지 않도록 생명주기를 보강했다.
6. 테스트가 직접 사용하는 `esbuild@0.28.2`를 직접 개발 의존성으로 명시했다.
   실행 의존성 추가/프레임워크 업그레이드는 없다.
