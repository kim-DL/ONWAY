# Phase 35 — 거래처 전경사진·카드·검색 입력 개선

2026-09-06. 거래처의 실제 전경을 확인할 수 있는 사진 1장, 최근 거래처 카드 개선,
주의 배지 선택값 보존, 출입 비밀번호와 연락처 입력 간소화를 적용한다.

## 사용자 경험

- 등록·수정에서 전경사진 한 장을 선택하고 미리보기·교체·제거한다. 사진을 선택하지
  않아도 저장할 수 있다. 사진 업로드 중과 거래처 저장 중 상태를 구분한다.
- 최근 거래처는 실제 열어본 최신 5곳만 유지한다. 12px 모서리, 상점 아이콘 또는
  작은 전경사진, 이름·주소·필요한 배지를 사용한다. 검색 목록 전체에 사진 다운로드를
  발생시키지 않는다. 상세의 납품 위치 영역에 전경사진을 표시한다.
- 신규 등록의 주의 배지를 서버가 무조건 신규로 덮어쓰던 부분을 수정했다.
  직원이 선택한 없음·신규·정보변경 값을 보존한다. 편집의 배지 해제 중복 입력도 제거한다.
- 비밀번호 상태는 비밀번호 등록·비밀번호 없음 두 가지 선택이다. 기존 unknown 기록은
  정보를 추측해 없음으로 바꾸지 않고 수정 시 둘 중 하나를 선택하도록 한다.
- 연락처는 이름과 전화번호를 입력한다. 기존 role/name은 함께 표시하고, 이름을 직접
  수정할 때만 단일 이름으로 저장하므로 다른 항목만 수정했을 때 기존 정보를 잃지 않는다.

## 사진 저장과 기존 앱 호환

인증·활성 직원·세션 및 권한 버전·App Check를 검증하는 서버 경계 안에서 처리한다.
최대 30MB 원본을 클라이언트에서 최적화하고 전송 파일은 10MB로 제한한다. 서버에서
형식·매직 바이트·용량·이미지 디코딩을 검증하며 WebP 썸네일/미리보기를 생성하고 EXIF를
제거한다. 사진 바이트는 거래처 목록에 포함하지 않는다.

업로드 단계와 거래처 저장을 분리하되, 사진 연결·거래처·revision·요청 잠금·감사 로그는
하나의 트랜잭션으로 확정한다. 저장 응답 유실 시 동일 요청으로 결과를 다시 확인한다.
사진 변경을 생략한 기존 클라이언트의 수정 요청은 기존 사진을 보존한다.
includeOverviewPhoto 옵션으로 사진 메타데이터를 요청한 클라이언트에만 반환하므로
이전 PWA의 엄격한 응답 검증과 호환된다.

사진은 공개 다운로드 URL을 발급하지 않고 인증된 읽기 요청으로만 제공한다. 현재
거래처에 연결된 버전인지 읽기 전후 다시 검사한다. 브라우저에서는 메모리의 폐기 가능한
Blob URL만 사용하고 로그아웃·오프라인·화면 해제 시 제거한다. Service Worker의 캐시
허용 목록에 거래처 사진/API를 추가하지 않는다.

미연결 사진은 24시간, 교체·제거된 사진은 복구 유예 30일 이후 한 시간 주기의 제한된
정리 작업에서 삭제한다. 정리 전 트랜잭션에서 현재 연결 여부를 다시 검사한다.
이번 작업에서 운영 거래처나 기존 사진을 일괄 변경·삭제하지 않는다.

## 모바일 검색

학교·담당 학교 추가·거래처·주소 검색·관리자 학교/직원/감사 검색에 공통 속성을 적용한다:
type=search, inputMode=search, enterKeyHint=search, autoComplete=off,
자동 대문자·자동 교정·맞춤법 검사 비활성화. 검색어를 계정/결제/주소 자동완성 입력으로
오인하지 않도록 입력 용도와 이름을 명확히 한다. 한글 조합 확정 Enter가 학교 선택으로
처리되지 않도록 보호한다.

학교 검색은 Visual Viewport에 맞춰 키보드 위 공간 안에서 결과를 스크롤한다. 높이가
작아지면 제목·여백·부가 안내를 줄이고, 핀치 확대는 가로채지 않는다.

첨부 화면의 열쇠·카드·위치 아이콘 바는 브라우저/OS의 자동완성 UI다. 웹앱에서 이를
모든 기기에서 강제로 숨길 수 있다고 보장하지 않는다. 표준 입력 힌트를 적용한 것과
실제 Android Chrome/Samsung 키보드에서 바가 사라지는지 여부는 구분해야 한다.
참고: [MDN 검색 입력](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/search),
[MDN 자동완성 제어](https://developer.mozilla.org/en-US/docs/Web/Security/Practical_implementation_guides/Turning_off_form_autocompletion).

디자인 스킬은 기존 밝은 톤을 유지하며 모서리·정보 위계·초점을 정리하는 데 적용했다.
React 검토 기준으로 사진이 있는 최근 카드와 상세에서만 필요한 코드를 불러오고,
사진 오류가 연락처·납품 정보 이용을 막지 않도록 구성했다.
