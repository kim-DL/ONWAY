# Phase 39 — 거래처 목록의 출입비번

2026-09-07.

- 최근 검색 거래처 카드와 전체보기의 compact 카드에 주소 바로 아래 출입비번을 표시한다.
  기존 일반 검색 결과는 이미 비밀번호를 표시하므로 중복 행을 추가하지 않는다.
- 기존 customerPasswordLabel을 재사용한다. registered는 문자열 그대로(앞자리 0,
  특수문자 포함), none은 없음, unknown/등록값 누락은 미등록으로 표시한다.
  none/unknown에 잔존 문자열이 있더라도 이를 실제 비밀번호로 노출하지 않는다.
- 공통 요약 행으로 기존 폰트·색상·카드 밀도를 유지한다. 긴 값은 잘라내거나
  말줄임하지 않고 줄바꿈하며, 카드 버튼의 aria-describedby에도 연결한다.
  글자 200% 확대에서 이름과 배지가 겹치던 기존 64px 배지 너비 제한을 제거해
  flex-wrap이 실제 글자 너비를 기준으로 줄바꿈하도록 보완했다.
- 전화·길안내·상세 열기와 최근 기록 정책은 유지한다. 최근 기록은 ID만 저장하며
  비밀번호는 현재 권한으로 조회한 고객 데이터에서 표시한다. 새 네트워크 요청,
  로컬 비밀번호 저장, 권한·서버·도메인 변경 없음.
