# Phase 42 — 사진 종료 연속성과 웰컴 컬러·모션

## 사용자 요청

- 사진을 닫을 때 셔터처럼 보이는 깜빡임 수정.
- 홈 헤드라인의 마지막 구절을 각 모드 선택 버튼의 텍스트 색상과 일치.
- 웰컴 네 원의 크기 변화, 조금 더 넓은 이동과 조화로운 다색 구성.

## 원인과 수정

- 사진의 종료 완료 직후 `settle()`이 유지 중인 Web Animations 프레임을 취소하고 `open` 상태로 되돌려 실제 언마운트 전에 큰 사진이 다시 보일 수 있었다. 흰 패널과 배경은 사진 전환이 끝날 때까지 불투명하게 남았다.
- 종료 프레임과 closing 상태는 언마운트까지 유지한다. 패널·사진·배경이 260ms 동안 함께 페이드된다. 빠른 닫기는 현재 사진 위치를 유지하며 사라지고, 확대 중이거나 원래 사진이 사라진 경우에도 잘못된 위치로 돌아가지 않는다.
- 닫는 중 사진 URL이 갱신되어도 진행 중인 종료가 다시 열기로 바뀌지 않도록 사진별 입장 효과와 창의 수명 관리를 분리했다.
- 헤드라인과 모드 버튼은 공용 CSS 토큰을 사용한다: 학교납품 `#1B64DA`, 거래처 `#247647`, 영업/홍보 `#FA6F42`. 밑줄 색상은 바꾸지 않는다. 고대비 모드에서는 시스템 텍스트 색상으로 대체한다.
- 영업/홍보 코랄 원색은 사용자가 지정한 기존 버튼 색상을 그대로 유지한다. 흰 배경 대비 약 2.8:1이므로 해당 색상에 대한 WCAG AA 대비 충족을 주장하지 않는다. 작은 본문/입력 텍스트에는 적용하지 않는다.
- 네 원의 크기는 이동 주기와 분리된 7.3/9.1/11.7/13.3초 주기로 변한다. 불규칙하게 느껴지도록 시작 위상을 다르게 하되 매 프레임 무작위 수나 리액트 상태 업데이트를 생성하지 않는다. 최대 크기와 궤적을 제한해 이름·문구와 겹치지 않는다.
- 팔레트는 블루·아쿠아·라일락·샴페인, 제이드·스카이·샌드·미스트, 코랄·모브·허니·민트로 모드별 조합했다. 기존 120×58 아트 영역은 그대로이며 원의 개수도 4개다.
- 기존 일시정지·탭 숨김·OS 모션 감소를 바깥 이동과 안쪽 크기 변화 모두에 적용한다. 새 라이브러리, 이미지, API, 데이터/권한 변경은 없다.
- 사용하지 않거나 최종 밝은 테마에 덮인 예전 헤드라인 색/세리프와 원형 장식·배경을 정리했다. 현재 최종 배경 디자인은 유지한다.

## 검증

- 최종 production build, ESLint, 앱/Functions TypeScript, PWA build gate, 성능 gate 통과. 기존 성능 예산은 올리지 않았다. 초기 JS 140,508B gzip, 공용 CSS 45,568B gzip, 지연 사진 UI CSS 1,129B gzip, 거래처 지연 JS 34,888B gzip.
- 전체 단위 테스트 974 통과, 환경 전용 3개 건너뜀.
- 전체 브라우저 106 통과 + 최종 사진/헤드라인/원 모션 집중 8개 재검증 통과.
- 종료 72% 프레임에서 패널·배경 투명도 감소, DOM 제거 전에 종료 애니메이션 취소 0회 확인.
- 빠른 닫기 3회, 확대 닫기, 학교 사진 뒤로가기, 포커스·스크롤 복원, 320/390/768 화면의 문구 비겹침 검증.
- 테스트는 합성 fixture이며 실제 직원 PIN 제출이나 운영 사진·거래처 데이터 작성은 하지 않는다. 실제 휴대폰/앨범 공급자 동작 전체를 대신하는 검증은 아니다.

## 사용한 가이드와 근거

- frontend-design: 밝은 기존 톤과 정보 위계를 유지하며 변화를 장식 영역에 제한.
- vercel-react-best-practices: CSS transform 기반, 독립적인 JS 프레임 루프 없이 효과 구현.
- Playwright: 기존 브라우저 검증과 프레임 관찰로 회귀 확인.
- [MDN Animation.cancel](https://developer.mozilla.org/en-US/docs/Web/API/Animation/cancel): 취소 시 애니메이션 효과가 제거되는 동작 확인.
- [web.dev Animation guide](https://web.dev/articles/animations-guide): 레이아웃 대신 transform 중심의 애니메이션.
- [W3C Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html): 불필요한 모션을 끌 수 있는 대체 동작 유지.
