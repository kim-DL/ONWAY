# Phase 44 — 영업/홍보 오로라와 급식실 안내

## 적용

- 영업/홍보 버튼의 코랄 계열과 연결되는 피치 `#FAAA9D`, 로즈 `#EFD3DF`, 라일락 `#DCD7EE`를 사용한다. 페이지에는 서로 다른 위치의 세 겹 오로라, 카드에는 피치·로즈 빛과 옅은 라일락 베이스를 혼합했다. 단색 채우기 대신 상단/가장자리에서 흐려지는 번짐이다.
- 영업 홈·활동·담당 학교·학교 상세의 주요 카드, 연락처·방문 기록·커뮤니케이션·현장 사진에 같은 표면 토큰을 사용한다. 본문과 기능 상태 색상은 유지하며, 작은 연락처 글자는 새 배경 위에서도 읽히도록 `#5F6A7A`로 보정한다. 납품·거래처 모드의 기존 오로라는 유지한다.
- 학교 상세는 기존 대화 → 연락처 → 이전 방문 순서를 유지하고, 현장 사진 바로 위에 급식실 위치를 추가한다. 건물·층·위치 설명·출입구·이동 동선·엘리베이터만 표시하며 검수시간/대차/계단/차량은 영업 안내에서 제외한다.
- 활성 영업 배정이나 사이클이 없더라도 정상 조회한 학교의 현장 프로필로 위치를 보여준다. 데이터가 없으면 위치 미등록·엘리베이터 미확인으로 표시한다. 없는 값을 1층이나 엘리베이터 없음으로 추정하지 않는다.
- 위치 수정은 급식실 정보와 엘리베이터만 입력받는다. 기존 대차/계단 상태를 보존하고, 검수시간·연락처·차량·메모는 patch에 포함하지 않는다. 기존 서버 권한과 revision 충돌 검사는 그대로다.
- 납품 화면과 위치 콘텐츠 컴포넌트를 공유해 두 화면의 정보가 달라지지 않게 한다. 여러 줄 위치 설명의 줄바꿈도 유지한다. 이미 조회한 fieldProfile을 사용하므로 추가 API나 데이터베이스 읽기는 없다.
- 320px 화면에서 영업 빠른 작업의 방문기록 문구가 두 줄로 갈라지지 않도록 간격을 조정했다. 버튼 높이와 글자 크기는 유지한다.

## 가이드와 검증 원칙

- frontend-design 스킬: 사용자가 선호한 밝은 분위기와 낮은 곡률을 유지하고, 코랄을 본문 전체가 아닌 배경 빛으로 사용한다.
- React 성능 가이드 및 로컬 Next CSS 문서: 기존 컴포넌트·지연 로딩 재사용, 스코프가 영업에 한정된 CSS 토큰, 신규 라이브러리·JS 애니메이션 루프 없음.
- 덮어써지던 이전 영업 테마 선언 84개를 정리했다. 기존 성능 예산은 높이지 않는다.
- 기존 테스트 fixture에 실제 영업 학교 상세를 렌더링해 검증한다. 사진·저장소는 합성 데이터이며 운영 직원 PIN 제출이나 운영 데이터 수정은 하지 않는다.
