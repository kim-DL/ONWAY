## 질문

각 항목은 `매우 그렇다 / 그렇다 / 보통 / 아니다 / 매우 아니다`로 답하고, 필요한 경우 짧은 이유만 기록한다.

1. 학교를 찾기 쉬웠는가?
2. 급식실 정보를 빠르게 찾았는가?
3. 사진 크기와 확대 방식은 편했는가?
4. 방문 기록은 번거롭지 않았는가?
5. 하트 관심도의 의미는 이해하기 쉬웠는가?
6. 내 구역과 전체 보기 구분은 명확했는가?
7. 버튼 반응은 자연스러웠는가?
8. 화면이 느리다고 느낀 순간이 있었는가?
9. 로그인 상태가 기대대로 유지됐는가?
10. Offline 또는 재연결 과정에서 막힌 일이 있었는가?
