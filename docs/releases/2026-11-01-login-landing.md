# 로그인 랜딩 리뉴얼

2026-11-01. 사용자 최종 시안 승인 및 Git/main·Hosting 운영 반영 요청.

## 변경

- 사진/영상 없이 SVG와 CSS 3D로 거래처·납품사진·재고 패널 표현.
- 급식길 블루 단일 배경, 로고 위/회사명 아래 중앙 정렬, 약한 그림자.
- 불필요한 소개/환영 문구·재생 컨트롤·모션 아래 구분선 제거.
- 6칸 PIN 표시와 접이식 도움말. PIN/Google 인증 로직과 잠금/오류 복구 유지.
- 모션 감소 및 비활성 탭 정지, 4.2초 자동 전환과 1.1초 이동.
- 로그인 전용 CSS는 기존 auth application 동적 경계에서 로드. 초기/기존 업무 화면 한도를 유지하고 새 전용 CSS에 16KiB raw/4KiB gzip 한도 및 precache 검사를 추가.
- 비교용 로컬 스크립트는 운영 export에 포함되지 않음.

## 검증

- 인증 관련 단위 55개 통과, 변경 TSX/스크립트 lint 통과.
- 운영 빌드/TypeScript, PWA, 성능, Hosting 산출물 검사 통과.
- 초기 CSS 23,045B raw / 6,504B gzip, 로그인 CSS 12,303B raw / 3,390B gzip.
- 운영 빌드 실제 브라우저 데스크톱 화면 확인. 앞선 시안에서 320/390px와 모의 PIN 오류 복구 확인.
- 운영 데이터/인증 제출/실제 휴대폰/PWA 설치 기기 확인은 수행하지 않음.
- 이전 운영 소스 d307af6의 CI 41262355323은 phase17의 납품사진 업로드 테스트에서 미사용 CSS preload 경고 단언으로 실패했음. 로그상 해당 실패는 데이터/권한 단언 실패가 아님. 이번 변경에서 납품사진 경로는 수정하지 않았고 이 이전 실행을 통과로 간주하지 않음.
