## 실패와 독립 검토

초기 새 브라우저 검사는 화면 크기 변경 전후의 좌표를 순차 읽어 섞었다. 진단에서 같은 오류를 네 번 포착했다. 같은 프레임의 사각형을 함께 읽고 요청한 화면·글자 크기 적용을 기다리도록 수정했으며 중앙 오차·48px·간격·겹침 기준은 완화하지 않았다. 최초 에이전트 실행의 한 실패는 상세 로그가 남지 않았으므로 처음부터 전부 통과했다고 표현하지 않는다.

이전 후보 `b1b1e46`의 CI 41830055000에서 기존 현장 검사가 카메라 SVG를 가정해 delivery-photos(15통과/1실패)와 phase17(82통과/19생략/1실패)이 실패했다. 실제 이미지의 경로·decode·중앙 정렬을 검사하도록 갱신했다. 정보 버튼의 기존 48px 높이도 복원하고 가까운 카드 검사에 이를 추가했다. 그 후보의 변경하지 않은 영업 경로 viewport 검사는 재시도 통과 1건이었다. 최종 후보 CI에는 해당 flaky 항목이 없다.

PSTACK balanced, 최대 워커 2개, 부모 모델·노력 설정 상속으로 별도 디자인 검토와 브라우저 테스트를 분담했다. 부모는 실제 diff·화면·로그를 확인했다. 독립 검토자는 좌표 진단 증거와 후속 테스트 변경까지 검토했고 중요한 미해결 지적은 없다. GitHub 자동 코드 리뷰도 최종 후보에 지적이 없었다.
