# 화면 주소 기준 경로 추천 및 카카오맵 길안내

## 수정

- 원래 납품 경로 추천은 거래처의 `deliveryPoint`가 없으면 주소가 있어도 거부했다. 카카오맵 길안내도 표시 주소와 무관하게 이 핀 좌표를 사용했다.
- 두 기능 모두 거래처 카드/상세 화면과 같은 주소 우선순위(`deliveryAddress.trim() || officialAddress.trim()`)로 주소를 검색한다. 좌표만 있거나 예전 주소 항목만 보는 방식으로 우회하지 않는다. 고객 문서의 주소·핀·수정 이력은 변경하지 않는다.
- 주소는 Kakao Local의 exact 주소 검색으로 변환한다. 건물/지번 단위의 유일한 결과만 사용하고, 동 전체나 여러 후보는 거부한다. 층·호 등 상세 표기는 검색 전에 정리하고, 경로 추천의 축약 주소는 저장된 시·군·구가 있을 때만 보완한다. 같은 주소는 요청 안에서 중복 검색하지 않고, 성공 결과는 서버 RAM에 최대 1,000개/24시간 보관한다.
- 경로 검색은 동시 4건으로 제한하고 거래처 정보·목록·권한을 외부 호출 전후에 재확인한다. 주소 변경은 추천 결과의 적용을 무효화한다. 추천 서버의 기존 호출 제한·감사 기록·request ID 보호를 유지한다.
- 길안내는 기존 `searchCustomerLocations`에 `addressOnly` 선택 입력을 추가했다. 기존 주소/상호 검색 동작을 유지하고, 새 모드에서는 키워드 후보를 섞지 않는다. 서버 권한 재확인과 클라이언트 인증 세대 확인 후 좌표를 사용한다.
- 목록/상세 길안내는 사용자 클릭 시 창을 확보하고 주소 확인 후 카카오맵 `/link/to/이름,위도,경도`로 이동한다. 팝업 차단 시 현재 탭을 사용한다. 실패 또는 늦은 응답에는 오래된 핀으로 안내하지 않는다. 우클릭 등 기본 링크 동작은 표시 주소 검색으로 연결된다.
- 길안내 API 호출 모듈은 클릭 시 지연 로드한다. 고객 화면 gzip은 36,939→37,373B(+434B); 해당 지연 번들 한도만 512B 늘렸다. 납품사진 JavaScript는 기존 10,483B를 유지하고 초기 로드·다른 기능 한도는 유지했다.

## 검증

- 활성 거래처 223곳 모두 표시 주소로 실제 Kakao 주소 검색 성공. 기존 별도 핀이 없는 6곳도 주소로 좌표 확인. 확인 대상 2곳을 포함한 8곳을 실제 화물차 경로 API로 계산해 중복/누락 없음과 마지막 지점 고정을 검증했다. 주소 변환 230ms, 경로 API 734ms는 이번 로컬 실행 계측이며 현장 평균이나 앱 전체 시간은 아니다.
- Aside 브라우저의 실제 카카오맵 웹에서 회사→확인 대상 두 거래처의 자동차 경로가 각각 9분/2.6km, 11분/4.7km로 표시됐다. 이는 일반 자동차 경로 웹 확인이며 실물 휴대폰 앱 전환·실주행·냉동탑차 통행 가능 검증은 아니다.
- 최신 버전의 로그인된 운영 급식길에서도 표시 주소를 사용하는 길안내 핸들러를 실행해, 운영 주소 검색 Callable 이후 카카오맵의 올바른 도착지 좌표로 연결되는 것을 확인했다. Aside의 기본 링크 클릭은 DOM 클릭 이벤트 없이 href 검색 링크만 열어 별도 DOM 클릭으로 앱 핸들러를 검증했다. 팝업 차단 시 현재 탭 이동 경로까지 관찰했다. 고객 저장/삭제는 실행하지 않았다.
- 주소 추천 관련 단위 38개와 Firestore 에뮬레이터 19개 통과. 길안내 최종 관련 단위 62개, 실제 목록/상세 컴포넌트 모바일·PC 브라우저 8개 통과. 브라우저 API 응답은 모의 데이터이며 오래된 핀과 다른 주소 좌표를 전달하는지, 핀 없음, 팝업 차단, 오류 복구를 검증했다. 타입·관련 lint·운영 build·PWA/Hosting/성능 gate 통과.
- 첫 주소 점검은 `officialAddress`를 기준으로 삼아 화면 표시 주소와 달랐다. 사용자 정정 후 화면의 우선순위와 일치시켰으며 주소를 재등록하지 않고 223곳 전체 검색 성공을 확인했다. 첫 배포 CLI 중단 전 원격으로 접수된 적용 서버 업데이트는 최종 `f8da51d` 재배포로 교체했다.
- 새 브라우저 fixture의 환경 플래그 누락을 수정했다. 초기 증상은 버튼 대기 시간 초과였으며 앱 오류가 아니었다. 첫 버전의 공유 repository 용량 증가는 클릭 전용 모듈 분리로 해결했다.
- 공식 규격: [Kakao 주소 검색](https://developers.kakao.com/docs/ko/local/dev-guide#address-coord), [Kakao 길찾기 URL](https://apis.map.kakao.com/web/guide/#routeurl).
