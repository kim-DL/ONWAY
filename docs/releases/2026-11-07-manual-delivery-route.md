# 직접 선택한 납품처 경로 추천과 수동 순서 편집

- 사용자 최종 점검·배포 승인으로 소스 `8b996c3`을 2026-11-07 22:35:32 KST 운영 Hosting `00b252fec9d9d286`에 배포했다. 직전 버전은 `318444ae7f371689`이다.
- 납품사진에서 `명세서로 등록`과 `인공지능 경로 추천`을 따로 열 수 있다. 추천은 기존 서버가 오늘 납품처 전체를 대상으로 계산하므로 명세서 등록 여부와 관계없이 직접 검색한 거래처도 포함한다.
- 추천 화면의 `납품처 추가 · 순서 편집`과 추천 적용 후 `순서 직접 바꾸기`를 기존 오늘 목록 편집기에 연결했다. 저장 후 추천 화면으로 돌아오며 납품사진 목록에도 같은 순서가 반영된다. 기본 내 납품처는 유지한다.
- 수동 변경은 기존 saveDay Callable과 revision 충돌 보호를 사용한다. 경로 API를 추가 호출하지 않으며, 편집 이후 이전 예상 시간·거리는 보여주지 않는다. 회사 출발·출발 전 2~20곳·마지막 거래처 고정 등 기존 추천 조건은 유지한다.
