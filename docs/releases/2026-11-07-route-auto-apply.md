# 추천 경로의 오늘 목록 자동 적용

기존에는 추천 계산 후 별도 적용 버튼을 눌러야 오늘 목록이 변경됐다. 이제 마지막 납품처 선택 후 추천을 실행하면 기존 저장 Callable까지 이어서 실행하고, 서버 확인 후 오늘 남은 납품처에 추천 순서를 반영한다. 사진 기록이 있는 거래처의 완료 상태와 수동 순서 편집은 유지한다.

저장 실패 시에는 추천을 재계산하지 않고 저장만 다시 시도할 수 있다. 응답 유실 시 중복 저장을 방지하도록 같은 추천의 저장 request ID를 재사용한다. 권한·revision·감사 이력 검사는 기존 서버에서 유지한다. 서버 및 데이터 스키마 변경은 없다.

## 검증

- 실제 화면 컴포넌트와 모의 repository를 이용한 모바일·PC 브라우저 14개 통과: 명세서/직접 검색 등록, 자동 적용, 기록완료 제외, 저장 지연, 실패/응답 유실 재시도, 수동 순서 변경. 수정 전 자동 적용 실패를 재현했다.
- 관련 단위 26개, 타입 및 관련 lint 통과. 최종 소스와 동일한 테스트 결과를 사용했고 불필요한 재실행은 하지 않았다.
- 이번 배포 전 `npm run build:hosting`과 PWA/Hosting/성능 gate 통과. 기존 공개 기능 플래그를 유지했고 성능 한도 변경 없음.
- 배포 후 두 운영 주소의 공개 응답 검사 통과, 각각 JS/CSS 99개 해시 일치, 로컬 출고 파일 127개 해시 유지.
- 실물 휴대폰·설치 PWA 및 인증된 운영 자동 저장 흐름은 미검증이다. 운영 데이터를 시험용으로 쓰지 않았다.
