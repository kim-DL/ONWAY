갱신된 카드에서 확인 카드 우선 배치, 한 줄 기억·제외 옵션, 새 건수 표기와 모드 버튼을 실제 화면으로 확인했다. 사용자가 해당 카드에서 직접 거래처를 선택하고 등록을 승인하여13곳 등록 완료로 바뀌었다. 사용자는 이 등록을 직접 수행했다고 명시적으로 확인했다. 이 결과를 되돌리거나 삭제하지 않았다.
