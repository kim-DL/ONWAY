# 2026년 11월 19일 거래처 모드와 앱 업데이트

## 사용자에게 보이는 변경

- 먼저 설치된 급식길에서 기존 ‘업데이트’를 누르면 새 화면에서 이번 릴리스 노트를 한 번 보여 준다. 새 업데이트 화면에서는 설치 전에 변경 내용을 읽고 ‘지금 업데이트’나 ‘나중에’를 선택할 수 있다. 다른 탭에서 작성한 내용은 유지되며 첫 설치에는 업데이트 알림을 표시하지 않는다.
- 변경 내용과 날짜는 대기 중인 서비스 워커가 직접 전달한다. 다음 앱 릴리스에서는 `src/features/pwa/release-notes.ts`의 고유 ID, 날짜와 현장용 설명을 함께 갱신한다.
- 거래처의 날짜별 사진 조회가 끝난 뒤에만 빈 기록으로 표시한다. 전송함 읽기 실패는 재조회로 복구하고, 전날 사진과 실패 사진은 거래처 행에서 해당 항목으로 이동한다.
- 현재 거래처·직원 권한·기기 보관 상태와 한도를 확인하면 촬영할 수 있다. 유효한 사진을 고른 뒤 연속 촬영이 시작되고, 닫은 뒤에도 서버 확인을 기준으로 완료 건수를 센다. 납품 순서 저장 재시도에는 동일한 요청 ID를 사용한다.
- 오늘 남은 납품처에서 카카오맵 자동차 길안내를 한 번에 연다. 같은 권한·거래처·주소에서만 최근 좌표를 재사용한다. 빈 전송함은 보관 건수를 먼저 확인한다.

앱 업데이트 알림은 GOV.UK의 알림 배너와 버튼 위계를 참고했다. 급식길의 아이보리 바탕과 짙은 녹색 버튼, 라임색 설치 아이콘을 사용한다. 휴대폰에서는 내용이 늘어나면 페이지와 함께 스크롤한다. [GOV.UK 알림 배너](https://design-system.service.gov.uk/components/notification-banner/) · [GOV.UK 버튼](https://design-system.service.gov.uk/components/button/)

## 검증과 측정

| 로컬 측정 | 이전 | 적용 후 |
| --- | ---: | ---: |
| 사전 조회 없는 길안내 첫 클릭 | 1회 · 158ms | 1회 · 157ms |
| 같은 거래처 길안내 재클릭 | 추가 1회 · 159ms | 추가 0회 · 8ms |
| 상세에서 거래처 선택 후 첫 클릭 | 클릭 때 1회 · 160ms | 사전 1회, 클릭 때 0회 · 9ms |

시간은 주소 조회에 150ms의 고정 지연을 준 Chromium 5회 중앙값이다. 알림은 320·390·430·1280px와 기본·200% 글자 크기에서 검사했다. 기존 화면에서 승인한 뒤 변경 내용을 확인하는 과정을 실제 로컬 정적 배포물 두 벌로 검증했다. 업데이트 전용 Chromium 6건과 iPhone 에뮬레이션 WebKit 3건, 전체 단위 2,154건, 사진 서비스 에뮬레이터, 타입 검사, ESLint와 PWA·성능·Hosting 빌드 검사가 통과했다. WebKit과 Chromium 검사는 데스크톱에서 실행했다.

첫 업데이트 브라우저 fixture에는 스타일 묶음이 빠져 있었다. 실제 스타일을 포함한 뒤 재검사했다. ESLint가 Playwright의 fixture 콜백을 React 훅으로 판별한 오류는 콜백 이름을 바꿔 해결했다. Next.js 16.4.3 빌드가 보안 경고로 중단되어 16.4.6으로 올린 뒤 운영 빌드를 검증했다. [Next.js 공식 릴리스](https://github.com/vercel/next.js/releases/tag/v16.4.6)
