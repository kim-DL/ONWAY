# 방문 동선 안정성 및 회사 브랜드 개선 — 2026-09-05

## 실제 원인과 재현

사용자 담당 16개 학교 중 대전대신고등학교, 대전둔원고등학교,
대전선화초등학교는 공식 교명·도로명 주소가 정확히 일치하는 학교 본체가
있었지만 교내 충전소·매점·체육관 후보도 별도 학교처럼 취급됐다.
3곳의 `MULTIPLE_PLAUSIBLE_CANDIDATES`가 전체 동선 요청을
`failed-precondition`(HTTP 400)으로 중단시켰다. 16개라는 개수 제한은 아니다.

## 판별과 복구 원칙

- 본체의 정확한 이름·주소 및 대전 지역 조건은 유지한다.
- 같은 주소, 본체 반경 500m 이내, 경계가 명확한 교명/지역 생략형 교명,
  부속시설 이름·업종이 함께 맞는 경우에만 부속시설을 중복 학교 후보에서 제외한다.
- 다른 학교, 분교·캠퍼스, 알 수 없는 접미사, 잘못된 업종, 지역 밖 후보는
  자동 확정하지 않는다. 원본 후보는 관리자 검토용으로 모두 보존한다.
- 위치 미확정, 서비스 연결 실패, 시간 예산으로 아직 확인하지 못한 학교를 구분한다.
- 미확정 학교명과 재시도를 표시한다. 선택과 첫 학교는 실패해도 유지한다.
- 사용자가 명시적으로 누른 경우에만 일부 학교를 이번 동선에서 제외한다.
  담당 배정은 삭제하지 않는다. 제외 대상이 첫 학교이면 대체 첫 학교를 직접 고른다.
- 잘못된 성공 응답이나 누락·중복 학교를 정상 결과로 표시하지 않는다.
- 동시 위치 확인 충돌은 최신 확정 좌표를 한 번 재조회한다. 관리자 확정값을
  덮어쓰지 않으며, 여전히 미확정이면 이어서 확인하도록 안내한다.
- 0,0·비정상/지역 밖 좌표와 이전 가능성이 표시된 기존 위치는 재검증한다.
- Kakao 장소 ID가 같아도 기존 확정 위치와 100m 넘게 달라지면 이전 검토가
  필요하다. 기존 관리자 확정 좌표를 덮어쓰거나 이전 가능성을 자동 해제하지 않는다.
- 응답의 모든 방향별 이동 구간, 학교 순서·구간 정보, 합계·도로/추정 표시가
  서로 일치하는지 확인한다. 수동 순서 변경에 필요한 구간 누락도 오류로 처리한다.

## 운영 검증

공식 주소와 실제 Kakao 응답을 이용해 16곳 모두 고신뢰도 일치를 확인했다.
운영 Firestore를 사용하는 실제 서비스 클래스 및 실제 도로 API로 검증했다.
위치 수정은 기존 매칭 서비스를 통해 수행하고, 변경 전 백업과 유지보수 감사
이력을 남겼다. 직원 로그인 토큰을 발급하거나 직원 PIN을 변경하지 않았다.

- 첫 학교: 대전외국어고등학교 → 16곳, 15개 도로 구간, 누락 없음.
- 첫 학교: 회덕초등학교 → 16곳, 15개 도로 구간, 누락 없음.
- 두 결과 모두 선택한 첫 학교 고정, 각 학교 정확히 한 번, `road` 모드.

이는 실제 계정의 모바일 PWA에서 버튼을 누른 테스트와는 구분된다.
인증·권한·모바일 클릭/복구 흐름은 Firebase 에뮬레이터의 브라우저 회귀 검사로 검증한다.

회귀 검사는 2/9/16/20곳, 21곳 거부, 첫 학교 변경, 16곳 중 일부 실패,
전부 미확인, 서비스 중단, 확인 지연 후 이어서 처리, 동시 사용자 충돌,
관리자 확정 위치 우선, 잘못된 좌표/응답키, 요청 중 중복 조작을 포함한다.

인증 콜백의 수명도 보강했다. 화면 정리 뒤 지연된 리스너 등록과 콜백,
이전 계정의 권한 응답이 현재 세션에 반영되지 않도록 보호하며 회귀 검사한다.
이는 개발 브라우저에서 관찰한 초기 React 경고의 직접 원인이라고 확정한 것은 아니다.

## 제한과 운영 안내

- 한 동선은 최대 20곳이다. 카카오 다중 목적지 API는 최대 30개 목적지,
  반경 최대 10km를 문서화한다. 확인하지 못한 도로 구간은 추정치로 표시하며
  전체를 실제 도로 결과인 것처럼 표시하지 않는다.
- 이 기능은 선택한 첫 학교에서 시작하는 추천 순서이지 수학적 최적해 보장이 아니다.
  방문·주차 시간과 미래 교통 상황은 총 이동시간에 포함되지 않는다.
- 지역 확대 시 현재 대전 좌표 검증 범위와 데이터 수집 범위를 함께 변경해야 한다.

참고: [카카오 다중 목적지 길찾기](https://developers.kakaomobility.com/guide/navi-api/destinations.html),
[Kakao Local 검색 응답](https://developers.kakao.com/docs/ko/local/dev-guide).

## 브랜드

원본 회사 로고는 변경하지 않는다. 기존 코드 기반 아이콘 생성기에 v4 출력 추가:
일반/Apple 아이콘의 심볼 너비 96%, maskable 약 78.6%(기존 66%).
Maskable은 실제 불투명 심볼 픽셀이 중앙 40% 반경 안에 드는지 검사한다.
앱 헤더에는 투명 회사 심볼과 `온누리종합식품`을 함께 표시한다.
한 번의 짧은 진입 애니메이션 및 포인터 반응만 사용하고 reduced-motion을 따른다.

manifest·Apple 메타데이터·favicon·캐시 버전을 함께 갱신하며,
이전 앱 코드가 깨지지 않도록 v3 파일은 남겨둔다.
기존 설치 아이콘 갱신 시점은 OS/브라우저에 따라 다르다.
새 아이콘이 계속 보이지 않으면 업데이트 확인 후 재설치가 필요할 수 있다.

참고: [Maskable 아이콘 안전 영역](https://web.dev/articles/maskable-icon).
