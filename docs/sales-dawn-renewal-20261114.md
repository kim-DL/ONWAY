# 영업 모드 새벽하늘과 선택 버튼 리뉴얼

사용자는 기존 선택 버튼의 흰색과 푸른 배경판이 새 분위기와 어울리지 않는다고 판단했고, 엷은 새벽하늘 그라디언트로 전반적인 재정리를 요청했다. 앞선 웜 펄 조합에서 배경만 바꾸는 대신, 선택 상태와 강조색도 함께 맞췄다.

## 최종 디자인

- 배경은 위에서부터 하늘색 `#e6edf6`, 연보라 `#eee8f3`, 옅은 로즈 `#f6e5e2`, 살구빛 `#f8f0e6`로 이어진다. 낮은 위치에 반투명 크림빛을 더해 새벽의 지평선처럼 보이게 했다.
- 카드와 4분할 버튼은 반투명 펄·라일락 계열이다. 세라믹 아이콘과 기존 배치, 지표의 중앙 정렬을 유지했다.
- 홈 범위, 활동 탭, 지역 필터, 학교 선택, 방문 동선 선택, 월 선택과 방문 기록의 선택 면은 `#e8dfed`, 글자는 짙은 자주회색 `#625174`로 정리했다.
- 선택된 항목은 색면뿐 아니라 테두리·밑줄·체크 등 기존 표시도 유지한다. 지역 필터는 hover가 선택 색을 흰색으로 덮지 않게 했다.
- 실제 완료·주의·오류 등의 의미색은 유지했다. 기본 흰색 입력창과 일부 유리 재질은 남는다. 앱 전체의 모든 흰색·파랑을 제거한 변경은 아니다.

## 구현 범위

`field-controls.css`의 영업 전용 토큰과 선택 상태, `sales-workspace.css`의 월 선택, `sales-route.css`의 동선 패널, 지역 필터와 동선 계획기의 CSS 모듈을 수정했다. CSS 다섯 파일만 바뀌며, 타입·처리기·권한·저장 계약·이미지·의존성에는 변경이 없다. 공통 파랑 변수의 이름은 기존 호출 관계를 유지하되 영업 범위 안에서만 짙은 라일락 계열 값으로 지정했다. 다른 모드는 기존 색상을 사용한다.

## 확인

홈·활동·지역 필터·동선 계획기의 관련 브라우저 34개를 한 차례 실행해 모두 통과했다. 네 화면 폭, 텍스트 확대, 키보드와 고대비, 다수 학교 동선, 선택 유지와 비활성 상태를 포함한다. 전체 CI와 전체 회귀는 사용자의 중복 검사 생략 지시에 따라 실행하지 않았다.

Aside에서 390px 홈 화면을 캡처하고 활동 화면의 상태와 이동을 확인했다. 활동 화면의 추가 스크린샷은 브라우저 CDP 캡처 시간 초과로 저장하지 못했으며, 이를 제품 오류나 활동 화면 시각 검증 완료로 바꾸어 보고하지 않는다. 관련 활동 화면의 자동 접근성·상태 검사는 통과했다.

독립 소스 검토는 선택 글자 약 5.50:1, 지역 선택 개수 약 4.86:1, 흰색 주요 버튼 글자 약 7.12:1을 확인했다. 기존 고대비 처리와 의미색, 모드 한정 범위를 유지한다. 전체 접근성 인증이나 실물폰 검증을 의미하지 않는다.

최종 운영 빌드 한 차례와 기존 성능·PWA·Hosting 파일 검사가 통과했다. gzip 기준 초기 JS 144,013B, 영업 묶음 14,298B, 기존 CSS+공용 사진 CSS 46,930B다. 기존 제한을 완화하지 않았다.

최종 소스와 운영 반영 결과는 배포 후 기록한다. 실물 휴대폰·설치 PWA·인증된 운영 저장은 이번 확인에 포함하지 않는다.
