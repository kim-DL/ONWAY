# 영업 밑줄 탭과 절제된 세라믹 아이콘

## 요청과 변경 범위

내 학교·전체 보기와 전체 지역·행정구 선택을 테두리와 배경 없는 텍스트로 바꾸고, 선택한 항목 아래로 밑줄이 이동하도록 한다. 활동 상태 탭과 업무 처리 계약은 유지한다. 새벽하늘 배경과 중앙 정렬, 기존 4분할 작업 배치는 유지한다.

학교 추가는 건물 없이 더하기 하나만 표시한다. 학교 찾기·학교 추가·학교 정리는 거래처의 기존 돋보기·더하기·목록 세라믹 원본을 재사용한다. 방문 동선은 같은 펄 화이트 재질과 낮은 채도의 회색 라일락으로 새로 생성한다. 공개 경로는 `public/ui/sales-ceramic-{search,route,add,organize}-v1.webp`를 유지하여 기존 명시적 PWA 사전 캐시를 그대로 사용한다.

## 구현과 검증 순서

기존 scope 선택값 두 가지와 district 옵션·선택값·측정용 DOM 참조가 데이터 형태다. 별도 선택 상태나 공통 탭 프레임워크를 추가하지 않는다. 고정 두 칸 범위에는 CSS 이동 밑줄을 쓰고, 가변 폭 지역에는 기존 측정 수명 주기를 활용한다.

작업은 탭 구현과 정적 이미지 준비를 독립적으로 진행한 뒤 합친다. 변경된 화면 검사, 독립 소스 검토와 Aside 합성 화면 확인, 최종 운영 빌드 및 산출물 검사 순으로 진행한다. 사용자의 중복 검사 금지 요청에 따라 전체 CI와 전체 회귀 검사는 반복하지 않는다. 실제 실패나 후속 수정이 있으면 해당 항목만 재확인한다.

## 이미지 출처와 생성 조건

내장 imagegen을 사용해 방문 동선 한 개를 생성했다. 거래처의 register·directory 이미지는 재질 참조, 이전 영업 route 이미지는 두 위치 핀을 곡선으로 연결한 의미 참조로 입력했다. 프롬프트는 펄 화이트 유약 세라믹, 부드러운 모서리, 얕은 중성 음영, 극히 옅은 회색 라일락 안쪽, 정면에 가까운 시점과 48px 식별성을 지정했다. 파랑·시안·금색, 바탕 타일·바닥·글자·반짝임·광채는 제외하고 실제 alpha 투명을 요청했다.

생성 원본은 Codex generated_images의 `exec-6f3a4dfa-73d2-4b28-9f23-429388684048.png`다. 투명 여백 정규화와 크기 축소 후 192×192 WebP로 저장했다. 나머지 세 개는 거래처 원본과 동일한 파일이며 별도 생성물이 아니다.

## 검증 및 배포 결과

영업 화면 12개는 첫 실행에 모두 통과했다. 지역 화면은 첫 실행 10개 통과와 2개 실패 뒤 최종 12개가 통과했다. 실패는 새 검사가 전역 동작 줄이기의 `0.00001s`를 `0s`로만 기대한 테스트 오류였다. 기존 허용 기준으로 수정했다. 독립 소스 검토에서 움직이는 밑줄의 이전 위치가 넘침 계산에 포함될 가능성을 찾아 실제 옵션의 끝을 기준으로 계산하도록 보완했고, 관련 지역 12개만 재실행했다.

320·390·430·1280px, 키보드, 가로 스크롤, 200% 글자 확대, 강제 색상, 동작 줄이기, 접근성, 아이콘 decode와 정리 상태를 확인했다. 변경 TSX와 테스트의 ESLint, `git diff --check`, 최종 운영 빌드와 성능·PWA·Hosting 산출물 검사가 통과했다. 기존 용량 한도를 변경하지 않았다. 전체 CI는 사용자 요청에 따라 반복하지 않았다.

Aside의 390px 합성 화면에서 새 아이콘과 내 학교 밑줄을 확인했다. 전체 보기 및 서구 선택 후 필터 결과는 접근성 트리로 확인했다. 추가 캡처는 Aside CDP 시간 초과로 저장하지 못했다. 실제 앱 오류나 검사 성공으로 해석하지 않는다. 합성 미리보기 탭과 서버는 종료했다. 실물 휴대폰·설치 PWA·인증된 운영 저장은 이번 검증에 포함하지 않았다.

소스 `ab49dfa18b81dbbd7aa5faa0cb1807ab60686b17`를 커밋·푸시하고 배포 파일 143개의 해시를 고정했다. `--project onnuriway --only hosting:onnuriway`로 2026-11-14 17:54:07 KST에 Hosting `94d5e1ad58311a1a`를 배포했다. 두 공개 주소 `https://onnuriway.com`과 `https://onnuriway.web.app`의 Hosting 검사와 각각 JS/CSS 109개·아이콘 4개의 SHA-256 일치를 17:54:29에 확인했다.

배포 전 운영 버전 `c493804ce74ce2b9`을 롤백 기준으로 기록했다. Functions·Rules·MCP Hosting과 운영 데이터는 변경하지 않았다. 후속 인수인계 문서 커밋은 앱 재빌드나 재배포를 하지 않는다.
