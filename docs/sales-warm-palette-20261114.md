# 영업 모드 웜 펄·살구·로즈·라일락 색상

사용자가 영업 화면의 은회색과 진한 글자가 무겁게 느껴진다고 피드백했다. 성별로 색 취향을 가정하지 않고, 사용자가 요청한 부드러움·온기·적당한 밝기를 기준으로 연구했다.

## 후보와 선택

실제 React 화면에 예시 데이터만 넣어 A 웜 펄·살구, B 로즈·라일락, C 아이보리·미스트 블루를 비교했다. 생산 소스와 분리한 `output/sales-palette/study.ts`에서 색상만 바꿨다. `unslop-ui`의 색상 점검과 `poteto-mode`의 Exhaust the Design Space 원칙을 적용했다.

사용자는 A를 선택한 뒤 로즈·라일락도 적절히 섞도록 지시했다. 넓은 바탕과 카드는 웜 펄·아이보리를 유지하고, 살구빛은 상단, 옅은 로즈는 측면, 라일락은 아래 가장자리에 배치했다. 버튼 하단에는 약한 로즈빛을 더했다. CSS 그라디언트로 구현하며 새 이미지나 의존성은 없다.

| 역할 | 색 |
|---|---|
| 바탕 | 웜 펄 `#f5eee8` |
| 상단 | 살구 `#f0e6df` |
| 측면 | 로즈 `#f1e4eb`, 투명도 약 50% |
| 하단 | 라일락 `#eee7f4` |
| 카드 | 아이보리 `#fffcf8` 기반 |
| 지표·범위 전환 | 따뜻한 중립색 `#f3ece6` |

최근 배포 전후 이력에서 기존 전체 배경 토큰은 바뀌지 않았다. 가독성을 위해 진해진 글자와 새 은회색 버튼이 무게감을 더했다는 판단은 실제 화면 비교에 따른 시각적 해석이다. 이번에는 글자를 전반적으로 옅게 만드는 대신 배경·카드·구분선·그림자의 회색기를 줄였다.

## 범위와 대비

제품 변경은 CSS 세 파일뿐이다. 영업 배경과 카드·버튼의 색/그림자, 활동 월과 목록 건수 및 상세 보조 글자의 색을 조정한다. 레이아웃, 중앙 정렬, 생성 세라믹 아이콘, 처리기, 권한, 저장 계약은 유지한다. 공유 색상 값을 바꾸지 않고 영업 전용 선택자와 클래스에 한정했다.

일반 글자는 최소 4.5:1을 기준으로 확인했다. [W3C의 대비 기준](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)은 실제 인접 배경과 글자 색의 대비를 평가하도록 설명한다. 모든 화면의 접근성을 인증했다는 의미는 아니다.

처음 실행한 영업 화면 검사 12개 중 10개가 통과하고 활동 검사 두 개가 실패했다. 배경이 따뜻한 중립색으로 바뀌면서 기존 활동 월 문구는 4.19:1, 목록 건수는 4.24:1이 됐다. 해당 글자를 기존 본문 보조색으로 바꾸고 실패했던 활동 검사 두 개만 재실행해 통과했다. 누름·선택 배경도 보완해 파랑 글자와 약 4.62:1을 확보했다. 상세 제목 위 보조 문구도 같은 가독성 색으로 맞췄다. 고대비 지원은 유지했다.

320·390·430·1280px 배치와 텍스트 확대, 키보드·고대비, 홈·활동 화면은 기존 관련 검사 범위다. Aside로 최종 혼합색 화면도 확인했다. 독립 소스 검토에서 다른 모드로의 누출이나 상태 계약 변경은 발견되지 않았다.

## 검증과 배포

사용자의 중복 검사 생략 지시에 따라 전체 CI·전체 회귀를 재실행하지 않았다. 바뀐 영업 화면 검사 한 차례와 실패한 두 항목 재확인, 최종 운영 빌드 한 차례, 성능·PWA·Hosting 파일 검사를 진행했다. 기존 검증 기준과 용량 제한은 유지했다.

최종 gzip 기준 초기 JS 144,015B, 영업 묶음 14,316B, 기존 CSS와 공용 사진 CSS 합계 46,892B로 기존 제한을 통과했다. 이 수치는 전송 용량이며 실행 속도 측정이 아니다. 실물 휴대폰·설치된 PWA·인증된 운영 저장은 검사하지 않았다.

배포 전 운영 Hosting 버전 `5d1089b7c770c369`을 롤백 기준으로 기록했다. 최종 소스 `9bb1f70b22fc78b3a3905e9e47875e75ee8c608c`와 파일 143개를 고정하고 Hosting만 배포했다. 새 버전은 `d077f0719efc4f6a`, 반영 시각은 2026-11-14 17:23:56 KST다.

`https://onnuriway.com`과 `https://onnuriway.web.app`에서 각각 공개 검사 38항목을 통과하고 JS/CSS 109개·아이콘 4개 SHA-256이 배포본과 일치함을 17:24:26 KST에 확인했다. Functions·Rules·MCP Hosting이나 운영 데이터는 변경하지 않았다. 이 릴리스의 전체 CI는 실행하지 않았으며 이전 소스의 결과로 대신 성공을 주장하지 않는다.
