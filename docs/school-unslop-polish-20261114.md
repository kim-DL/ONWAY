# 학교 모드 가독성과 세라믹 아이콘 개선

2026-11-14. 사용자가 `$unslop-ui` 점검·개선과 만족할 만한 검증 결과에 따른 운영 배포를 요청했다.

## 방향과 점검

- 제품 — 배송 담당자가 학교를 찾고 검수시간·급식실 위치·연락처를 확인하는 급식길 학교 모드.
- 성격 — 차분함, 또렷함, 현장 중심.
- 재질 — 기존 파란색과 유리 화면, 거래처 홈의 흰 세라믹과 연한 파란 유리.
- 강조 — 검색의 세라믹 돋보기와 학교 건물 아이콘, 상세의 검수시간.
- 일관된 표시 — 학교급 식별 표시는 보존하고 이동·검색 아이콘에 같은 재질을 사용한다.

Aside에서 합성 데이터로 실제 AppShell을 열어 기존 화면을 살폈다. 검색 설명·최근 방문 시각의 작은 글자, 검색 결과의 9~11px 주소·상태, 작은 상세 연락처 구분, 좁은 화면의 제목과 빠른 작업 줄바꿈을 확인했다.

## 반영 내용

- 홈의 검색 설명, 최근 학교의 구분·방문 시각을 14px로 맞췄다. 학교명은 16px이며 긴 이름을 줄바꿈한다. 모바일 방문 시각은 학교명 아래에 둔다.
- 기존 세라믹 돋보기를 재사용했다. 학교 건물 아이콘을 새로 생성해 빈 최근 목록과 검색 결과에 적용했다. 192×192 투명 WebP, 9,266바이트이며 고대비 검색에서는 기존 선 아이콘을 표시한다.
- 검색 주소·일치 유형·현장정보·사진 수·안내를 14px로 키웠다. 검색 결과는 내용 높이에 맞춰 늘어나고, 제목은 좁은 화면에서도 한글이 자연스럽게 이어진다. 일부 기술 문구를 실제 검색 안내로 바꿨다.
- 상세의 구분·연락처·수정 버튼을 14px로 조정했다. 하단 빠른 작업은 아이콘 아래 글자와 최소 64px 높이를 적용하고 사진 버튼에 카메라 표시를 사용한다.
- 검색을 닫을 때 초점이 사라지는 기존 문제를 수정했다. 원래 진입 버튼이 남아 있을 때만 초점을 복구한다. 이 초점 복귀 처리는 공유 검색 컴포넌트의 영업 모드에도 적용된다. 재질·문구·글자 크기 변경은 학교 모드로 제한했다.
- 기존 학교급 식별, 유리 내비게이션, 업무 순서, 권한과 저장 계약은 유지한다.

아이콘은 내장 이미지 생성 도구로 제작했다. 프롬프트의 핵심은 “흰 유약 세라믹 한국 학교 건물, 연한 파란 유리창, 부드러운 왼쪽 위 조명, 48px에서도 읽히는 단순한 형태, 글자·배경 없는 투명 이미지”다. 거래처 아이콘의 재질을 참고했으며 공개 정적 파일만 사용했다.

## 검증과 수정 이력

- 관련 단위 검사 43개 통과.
- 기존 거래처·모드 이동 화면 검사 22개 통과.
- 학교 홈·검색 4개, 학교 상세·수정·사진·공유 영업 상세 10개 통과. 모바일·데스크톱 프로젝트, 320/390/430/1280px 홈·검색 및 320/390/768px 상세를 포함한다.
- 200% 루트 글자 크기, 고대비·동작 감소, 44px 이상 홈 조작 영역, 키보드 진입·종료 초점, 접근성 자동 검사, 이미지 로딩, 가로 넘침 및 검색 결과 본문의 행 내부 배치를 확인했다. 200% 루트 글자는 실제 브라우저 줌이나 실물 휴대폰 시험을 대신하지 않는다.
- 새 회귀 검사에서 초점 복귀 누락을 재현한 후 수정했다. 시각 검사에서 검색 결과의 세로 겹침을 발견해 `grid-auto-rows: max-content`로 수정하고 세로 경계 검사도 추가했다.
- 최초 성능 검사의 legacy CSS gzip 45,775B 제한 초과와 후속 학교/공유 합산 제한 초과를 수정했다. 제한값은 변경하지 않았다. 학교 화면의 덮어써진 선언과 현재 DOM에서 사용하지 않는 과거 사진 최적화 안내·사진 교체 배지·직접 자식 저장 버튼·상세 보조 글자 스타일을 정리했다.
- 타입 검사, 변경 TS/TSX ESLint, Git 공백 검사를 수행했다. 배포 결과와 최종 빌드 검사 수치는 아래에 기록한다.

운영 시험 데이터 쓰기, 전체 원격 CI, 실물 휴대폰과 설치 PWA 조작은 수행하지 않았다. 합성 화면의 버튼 조작·저장 실패/재시도·권한 검사는 운영 데이터의 실제 쓰기 검증과 구분한다.
