# 거래처 모션·재고 인사 타이포 — 로컬 구현

기준일: 2026-10-22. 로컬 릴리스 준비 검증 완료이며 CI·운영 배포 결과는 후속 릴리스 기록에 남긴다.

## 확정한 방향

- 사용자가 캐릭터 작업을 철회했다. 캐릭터·Helix 시안은 제품에 포함하지 않는다.
- 재고 직원 화면은 기존 시간대별 개인 인사말의 타이핑만 사용한다. 장식이나 큰 제목을 추가하지 않는다. 관리자 재고 화면은 기존 구성을 유지한다.
- 거래처 홈은 학교납품·영업에서 쓰던 네 원 장식을 같은 인사 컴포넌트로 사용한다. 첫 제목 문구 바로 뒤 8px에 배치하며, 학교납품·영업의 기본 모양과 속도는 유지한다.

## 구현

- `WelcomeGreeting`에 인사말만 표시하는 `copy`와 거래처용 `customer` 변형을 추가했다. 타이핑·정지 설정·동작 줄이기·가시성 처리는 기존 기능을 공유한다. 장식이 없는 경우에도 인사말의 IntersectionObserver를 구독한다.
- 거래처는 96px 장식 영역에서 기존 원본을 0.78배로 표시한다. 좁은 컨테이너는 기존 72px/0.6배 보조 구도를 사용한다. 화면 끝으로 밀어내는 열 배분을 사용하지 않는다.
- 거래처 전용 마감은 기존 거래처 배색에 정적인 내부 명암과 작은 그림자를 더했다. 넓은 외곽 광채를 줄였다. 기존 네 궤도와 독립적인 크기 변화를 유지하면서 궤도 주기를 6.4/8.4/5.8/10.8초로 늘려 속도를 낮췄다. 움직이는 속성은 transform/opacity이며 매 프레임 JS를 추가하지 않았다. 거래처 전용 CSS에만 마감을 두고 재고 인사는 기존 muted 스타일을 재사용해 공통·개별 용량 기준을 유지한다.
- 거래처 검색 헤더에서는 인사말·장식이 함께 접힌다. 재고 인사는 보관 장소 위 13px 문구만 사용하며 검색·실사 상태를 변경하지 않는다.

## 검증과 한계

- 관련 단위 15파일 138 PASS: app-shell, 고객 홈, 재고 인사·UI·workspace lifecycle·등록 계약.
- 전체 단위 첫 로컬 실행은 1,797 PASS/15 기존 SKIP, Functions 사진 runtime identity 한 검사의 5초 module import timeout으로 실패했다. 해당 Functions 소스가 변경되지 않았음을 확인하고 같은 검사 파일만 분리 실행해 4 PASS(전체 3.09초, 테스트 2.80초)다. 동시 빌드·전체 검사 때의 부하 가능성은 있으나 정확한 timeout 원인은 미확정이다. 관련 최종 UI 단위 138개와 후속 집중 8개도 PASS다.
- 기존 welcome 브라우저 회귀 mobile Chromium 25 PASS, 재시도 0이다. 운영 형식 build/PWA/성능/Hosting gate PASS. 초기 공통 CSS gzip 상한 초과는 거래처 전용 스타일 분리로, 후속 거래처 CSS raw 49,449B 및 49,256B 초과는 중복·선택자 정리로 해결했다. 검사 스크립트와 상한은 변경하지 않았다.
- 전체 lint PASS, 클래스명 타입 보완 후 변경 TSX의 집중 lint PASS. 앱·Functions typecheck PASS. 최초 typecheck의 CSS Modules optional className 오류는 빈 문자열 fallback으로 수정했다.
- 실제 제품 React 컴포넌트를 esbuild로 묶은 합성 UI 미리보기에서 320/390/740px 가로 넘침 없음, 거래처 문구/장식 간격 8px, 원 4개, 재고 장식/제목 0개를 확인했다. 프레임별 viewport로 CSS media query를 적용했다. 운영 앱 전체 인증·데이터 흐름 검증은 아니다.
- 재고 pending → typing → complete, 공통 모션 정지/재개, reduced motion, 거래처 검색 시 장식 제거, 화면 밖 정지/재개 PASS. visibilityState를 바꾼 합성 이벤트의 정지/재개도 PASS다.
- 새 탭 전환 실험에서는 해당 자동 브라우저가 visible 상태를 유지했다. 이를 실제 백그라운드 검증으로 주장하지 않는다. 실제 직원 기기·설치 PWA의 홈 복귀 인수는 별도다.
- 공개 비교판은 `http://127.0.0.1:4318/`이며 ignored `output/welcome-reference-20261022/`에 생성했다. 정적 합성 목록·보관 장소와 실제 인사/홈 컴포넌트를 사용한다. `output/playwright/welcome-modes-20261022.png`에 시각 검토 자료를 보관했다.
- 사용자가 이 변경의 커밋·병렬 CI·Hosting 운영 배포·배포 후 검증·로컬 동기화를 승인했다. 최종 커밋에서 기존 검증 기준과 병렬 CI 정책을 따르며 실제 CI·배포·동기화 결과는 후속 릴리스 기록에서 구분한다.
